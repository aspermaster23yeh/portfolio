# Michael Robles — Portfolio

Portafolio personal de **Michael Robles** (`@aspermaster23dev`), con estética Apple.

Design system: [`DESIGN.md`](./DESIGN.md) instalado vía `npx getdesign@latest add apple`.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion

## Empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Personalizar

- Identidad: componentes en `src/components/`
- Proyectos: `src/data/projects.ts`
- Tokens Apple: `DESIGN.md` + `src/app/globals.css`
